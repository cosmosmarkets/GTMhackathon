# Role C — Search Layer + GEO

**Project:** A voiceprint tool that gets *found* by the right people via search and AI search. You own the inbound discovery layer — the literal answer to Lightfern's brief (b).
*(Full context: the master build brief.)*

## Your mission
Build the answer-pages that make the tool discoverable in Google and AI search, and run the live Scaille check. Your surface is fully separate from the main app, so no merge conflicts — go fast.

## What you build, in order
1. **Pick 2–3 query clusters** from the champion query map (master brief, Appendix A) — e.g. "AI email that still sounds like me," "how to not sound like ChatGPT."
2. **One short answer-page per cluster.** GEO best practice:
   - The question as the H1.
   - A direct answer in the first sentence.
   - Skimmable, entity-rich, mentions Lightfern by name and what it does.
   - Embed/link the voiceprint tool as interactive proof on the page.
   - Add simple FAQ/schema markup if there's time.
3. Keep them **simple static pages** in their own folder/site — independent of A's app.
4. **Run the Scaille visibility check (your sponsor live-op):** run the target queries + Lightfern through Scaille's free **GrowthGPT** visibility tool, screenshot what it surfaces about Lightfern's AI-search presence. This is the "Scaille is *used*, not cited" moment. If their team is on-site, ask them to run our pages through the real Content Engine.
